# InsureDesk — Feature List
> AI-Powered Desktop Workspace for Insurance Agents

---

## 1. Core Features

### 🖥️ Desktop Dashboard
- One place to manage all customers and policies
- Supports Great Eastern, Allianz, and AIA portals
- English, Malay, and Chinese UI

### 🤖 Browser Automation
- Auto-login to insurer portals
- Auto-fill forms, search policies, submit claims
- Session persistence — login once, no need to re-login after restart

### 📄 Policy Management
- Track every policy across multiple insurers
- Status: active, renewal due, lapsed, claimed
- Search and filter by customer, insurer, policy type

### 📎 Document Management
- Upload PDF policy documents
- Auto-extract structured data (coverage, premium, dates)
- File tagging and search

---

## 2. Smart Features

### 🧠 AI Assistant (Marry)
- Conversational AI — ask about customers, policies, tasks
- Voice input support
- Remembers customer context across sessions

### 📊 Business Analytics
- Renewal rate tracking and trends
- Claims ratio analysis
- Customer lifetime value scoring
- Daily business briefing

### 🔔 Smart Reminders
- Renewal alerts (30/14/7 days before expiry)
- Coverage gap detection
- Life event triggers: marriage, newborn, education, retirement

### 👥 Team Collaboration
- Multi-agent accounts
- Task assignment with workload balancing
- Team knowledge base sharing

---

## 3. Automated Workflows

### 🔄 Daily Operations
1. **Open InsureDesk** → See today's tasks instantly
2. **Search Policy** → Auto-opens insurer portal and searches
3. **Renew Policy** → One-click navigation to renewal page
4. **Submit Claim** → Auto-fills the form, you just confirm

### 📋 Morning Brief
- Opens with a daily summary of important items
- Renewal reminders, pending claims, new leads
- AI-suggested action items

## 4. Technical Requirements

| Item | Detail |
|------|--------|

| **NOT needed** | ❌ Python · ❌ Chrome · ❌ Any browser drivers |
| **Offline** | Customer data and policy records available offline |
